生成器逐函数翻译自 AB+ v1.06 的楼层生成代码。已与引擎核对：9,774 个地下室种子的引擎日志逐一一致；6,000 个引擎整层导出（第 1–8、10、11 层的全部变体）逐房间一致，包括隐藏房和超级隐藏房的位置。 核对条件：全部成就解锁、以撒、没有饰品。依赖饰品和道具的分支（银元、血冠、碎卡片、黑蜡烛等），以及正常开局时第一层的类型选择，还没在引擎里核对。

"隐藏房概率"只用玩家看得见的信息计算：地图、各房间的布局及其门位（布局可以从房间内容认出），再按生成规则推断隐藏房和超级隐藏房的联合后验。它和种子无关。在引擎楼层上，按它炸墙第 1 颗就炸中隐藏房的概率是 88%，超级隐藏房是 76%。

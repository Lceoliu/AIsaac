找隐藏房

选项
进每一层时的资源

单位是半颗心。硬币、钥匙和血量会影响赌博房、宝库、骰子房、挑战房和卧室会不会出现。

选一个种子，把藏起来的房间找出来

  1. 选游戏版本，输入种子，或者随机来一局。
  2. 在小地图上点墙外的格子，用炸弹炸开。忏悔+ 还能用红钥匙开红房间。
  3. 彩色格子是按生成规则算出的概率，只用你看得见的信息。

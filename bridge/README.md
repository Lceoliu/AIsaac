## 当前入口

主线为 [AB+ 原生 Linux 桥接与 token 训练管线](abplus/README.md)。引擎层在 [engine](engine/README.md)，部署在 [ops](ops/README.md)，模型在[架构文档](../docs/ENV_ARCHITECTURE.md)。旧 J460 桥接和 Windows worker 保留供历史校准、回放与维护，不再承担当前训练主线。

## J460 保留的接口边界

同步 `reset/step/observe` 必须保持原版逻辑推进与合法输入；读取可见状态不等于可以使用任意内存字段。单房间任务检查房间身份，真实跨房任务保留血量、资源和自然转场，不偷偷补血或重置状态。

旧单房间模式的 `Close+Bar` 与换房断言用于防止“炸门离开后误判胜利”，不能移植成整局策略禁止开门的规则。

## 已完成的历史故障结论

| 问题 | 保留结论 |
|---|---|
| 归档解析偶发空路径/空流 | 对已识别的物理容器路径交由原生解析；只处理真实磁盘文件，不能把嵌套 `.a` 容器全部改成 OS 路径。内部失配写入点未完全定位，不把缓解冒充根因全部查清。 |
| 字体 shader 栈故障 | 有独立诊断/守卫路径；不能把不崩溃与跳渲染玩法等价混为一谈。 |
| 退出时驱动异常 | 与归档和房间边界问题分开处理；worker 回收成功不代表其他两类已修复。 |
| 跨房假胜利 | 单房环境严格核对房间身份，离开未清房不是清房。已撤回的假胜利不计入成绩。 |

2026-09-20 最终历史验收：20 次冷启动通过；2048 步 PPO、64 epoch、17 个结束回合均死亡，参数 L2 改变量 1.318380；另一个可见战斗检查 5 局均死亡，渲染 5763 次、字体调用 74919 次。两类长测与冷启动未观察到崩溃，但**没有证明战斗能力达标**。

原始证据保留在历史运行目录与 Git；长篇原生崩溃调查、L1 可行性过程和旧训练场计划已并入本入口及[相关工作](../docs/RELATED_WORK.md)，不作为未完成待办重复列出。原生加速实现与构建入口见 [turbo](../turbo/README.md)。
